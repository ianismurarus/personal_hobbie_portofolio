# Electric Guitar Portfolio & Study Archive

A responsive, bilingual (**EN / RO**) personal portfolio and educational archive dedicated to electric guitar technique, music theory, and live performance.

**Live Demo:** [https://ianismurarus.github.io/personal_hobbie_portofolio/](https://ianismurarus.github.io/personal_hobbie_portofolio/)

## Features
- **Interactive Web Audio API Tuner:** Synthesizes standard guitar tuning frequencies (`E2`–`E4`) directly in the browser with zero external audio dependencies.
- **Bilingual Switch (`EN / RO`):** Instant client-side localization with English as default and persistent `localStorage` state.
- **Midnight Stage & Studio Daylight Themes:** Smooth Dark/Light mode toggle synchronized across all pages.
- **Responsive Architecture:** Adaptive CSS Grid/Flexbox layout with 16:9 YouTube embeds and scroll-reveal animations.

## Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Custom Properties, Glassmorphism, Grid/Flexbox)
- **Vanilla JavaScript** (ES6+, Web Audio API, IntersectionObserver)
